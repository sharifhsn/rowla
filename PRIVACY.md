# Rowla privacy statement

Effective date: October 4, 2026.

Rowla needs no account. It has no telemetry, advertising, remote crash reports, or remote screenshot storage.

Accessibility permission lets Rowla discover and control application windows. Optional Screen Recording permission lets Rowla capture local window thumbnails. Preview images stay in memory. Rowla does not save or transmit these images.

Rowla stores preferences, aggregate local diagnostics, and optional local crash logs on your Mac. They use `~/Library/Application Support/Taskbar Rust/` for compatibility with earlier builds. The user guide describes removal. No Rowla server receives these files.

This beta has no update feed. Rowla does not perform automatic network update checks. Downloads and public support use GitHub, which applies its own [privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). Public issue reports and attachments are visible to others. Include only information that you want to make public.

You can disable thumbnails and local crash logs in Preferences. You can revoke Rowla's permissions in System Settings. Without Accessibility permission, window discovery and controls cannot operate. Without Screen Recording permission, Rowla cannot capture new thumbnails.

For questions, use this repository's Issues page. Do not submit passwords, private documents, or unredacted personal information.
