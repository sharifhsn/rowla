# 0.2 beta validation

Check date: October 5, 2026. Local host: Apple Silicon, macOS 26.6.2 (25G83).

The public bundle declares macOS 15.2 in its manifest and executable.
The bundle contains six Mach-O binaries. The Sparkle binaries declare macOS 12.0.

## Native checks

The fixed signed bundle passed 20 UI cycles per case.
The checks include compact previews, single-line titles, cursor recovery, minimized previews, hovered close commands, pins, and Sort.
The new capture controls, shortcut import controls, deferred Sort, Show, and Hide also passed.
The check recorded 624 successful hit tests, no misses, and no active-feedback failures in 606 checks.

Four alternating activations of disposable fixture windows passed earlier in the same source build.
The slowest activation took 158.62 ms. Minimized close affected only the target fixture window.
These results do not establish reliability for every application or concurrent desktop automation session.

All three signed shortcuts imported through Preferences and executed with exit code zero.
The Hide shortcut hid the bar. The Show shortcut restored it.

macOS first requested permission to open the app. The CLI also requested permission to return its local URL output.
The obsolete QA duplicate was removed. Existing user shortcuts were preserved.

## Preview and memory measurements

Each capture method used two disposable windows and 20 cached hover checks.
The checks include rapid cancellation and native buffer release after idle time.
The host also had other active work. These results are functional measurements, not an isolated speed comparison.

| Measurement | Stream | Snapshot |
| --- | ---: | ---: |
| Cached hover to preview, p95 | 4.35 ms | 7.11 ms |
| Capture completion, p95 | 437.86 ms | 418.93 ms |
| Initial warmup | 1460.99 ms | 1469.91 ms |
| Highest sampled process RSS | 99.16 MiB | 95.63 MiB |
| Last sampled process RSS | 94.56 MiB | 92.20 MiB |
| Cached bitmap bytes | 1,732,608 | 1,732,608 |
| Idle native buffers released | Yes | Yes |

Both methods passed. Stream remains the default.
The cache still permits at most 16 MiB and 32 images. Native buffers require additional memory.

The worker permits one native capture operation. Stream mode uses a three-buffer queue.
These finite samples do not prove that every path is free of memory leaks.

## Reproducibility and limits

The final tested executable SHA-256 is:

```text
ce2dd4be8299bf9b4d3f11b57db47379c56475ca50b3adbdeec283a5a1155a80
```

The source passed Rust formatting, all-target tests, Clippy with warnings treated as errors, and shell syntax checks.
The Python suite passed 19 checks. One opt-in certificate check was skipped.
The signed shortcut resources match the reviewed source files and the bundle exactly.

CI checks macOS 15 and 26 on Apple Silicon and Intel.
CI cannot prove permission-dependent capture or controls. The exact macOS 15.2 point release and macOS 27 need desktop checks.
Independent installation, external displays, Spaces, fullscreen, sleep/wake, and revoked permissions need broader beta coverage.
